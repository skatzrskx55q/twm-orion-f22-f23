# TWM ORION — единый исследовательский цикл F22–F23 (05.11.2026)

**ГЛАВНОЕ:** Впервые получен положительный, независимо подтверждённый результат полностью автономного H90 для **обучаемой непрерывной причинной динамики**. Новая модель не выбирает готовые маски и не вызывает teacher в нейронном forward.

**СТАТУС БЕЙСЛАЙНОВ:**
- **Официальный общий baseline: TWM ORION NC3 — НЕ ИЗМЕНЁН.**
- **Новый исследовательский эталон (task-specific reference baseline): TWM ORION F23 Adaptive Causal Dynamics**, только на 6-узловых непрерывных мирах. F22 — необходимая обученная основа.
- Называть F23 «NC4» запрещено до сопоставимого экзамена на исходной типизированной задаче NC3, включающей другие правила, структуры и семантику отношений.

## Численные итоги независимых экзаменов

| Экзамен, допуск всего состояния 0.05, без восстановления эталоном | F21-P2 | F22 | F23 |
|---|---:|---:|---:|
| Родное гладкое семейство F21, 64 H90 | 0/64 | **63/64** | Не основной gate |
| Три новые формы отклика, 96 H90 | 0/96 | 33/96 | **90/96** |
| Три новых топологии с новыми формами отклика, 72 H90 | 0/72 | 32/72 | **69/72** |

На 640 новых запросах родного семейства F22 дала 640/640 в пределах максимальной ошибки 0.02 против 75/640 у F21-P2.

**ВНИМАНИЕ:** переносимые миры всё ещё имеют фиксированные шесть узлов, непрерывные параметры и числовые отношения; нет создания/удаления рёбер, дискретных свойств и новых классов операций. В F23 используются 96 отдельных наблюдений-переходов на мир, в F22/F21 обычно было шесть. Для независимых F23 экзаменов контроль F22/F21 получил те же 96 наблюдений, хотя ранее не обучался на таком бюджете.

## Содержимое
- `code/orion_f22.py` — первоначальный замороженный F22 source, hash зафиксирован до EXAM.
- `code/orion_f23.py` — расширенное представление и адаптация нелинейной формы (включая сохранённые отрицательные альтернативы).
- `code/reproduce.py` — полная повторная оценка EXAM, H90, трёх новых механизмов и OOD-графов.
- `code/retrain.py` — независимая репликация обучения F22 на TRAIN/DEV, **не битовое повторение исходной инициализации**.
- `configs/` — зафиксированные протоколы и SHA256, включая F23 transfer + structural OOD.
- `checkpoints/` — два F22 checkpoint, два F23 adaptative reference checkpoint и три исторических DEV-кандидата.
- `results/` — индивидуальные массивы всех испытаний, 90-шаговые траектории, постфактум CI, QA.
- `docs/TECHNICAL_REPORT_RU.md`, `PLAIN_LANGUAGE_RU.md`, `BASELINE_DECISION_RU.md`, `HISTORY_APPEND_RU.md`, `NC3_HISTORICAL_GATE_AUDIT_RU.md`.
- `upstream_F21.zip` — **НЕИЗМЕНЁННЫЙ полный архив F21**, с вложенными F20→F0→NC3 и предыдущими разработками.
- `MANIFEST_SHA256.txt` — SHA256 каждого файла внутри внешнего пакета.

## Повторная проверка

Из корневой папки распакованного исследования:

```bash
python code/reproduce.py --scope smoke
python code/reproduce.py --scope all
```

При первом запуске `reproduce.py` распаковывает `upstream_F21.zip` в `dependency/`. Без Интернета; PyTorch, NumPy и SciPy. Воспроизводимость H90 проверена из чистой распаковки по сохранённым checkpoint. Сведения о новом TRAIN-механизме находятся только в данных или офлайн-симуляторе, не в forward.

## Научная оговорка

F23 **не** является универсальной физикой и **не** проходит исторический gate полного NC3 (тот экзамен для F23 не исполнялся). Положительный результат честен внутри заданного числового подкласса; перенос на исходные типизированные законы ещё предстоит разработать. Не менять официальный NC3.
