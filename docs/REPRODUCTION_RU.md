# Руководство по воспроизведению

1. Установите зависимости по [README_RU](../README_RU.md). В среде подготовки проверялся только CPU.
2. `python verify_integrity.py` проверяет SHA-256 всех распространяемых исходных файлов без ML-зависимостей.
3. `python run.py check` выполняет `python code/reproduce.py --scope smoke` в `research/TWM_ORION_F22_F23`. Код ошибки сохраняется, в том числе при провале теста.
4. `python run.py --keep ../experiment demo` выполняет `python code/reproduce.py --scope all`. Копия данных и новые результаты остаются в `../experiment`. Перед длительным запуском прочитайте исходный README.
5. Обучение или расширенный эксперимент: `See code/retrain.py and docs/TECHNICAL_REPORT_RU.md / См. исходный отчёт`. Работайте в отдельной копии, сохраняйте оригиналы и учитывайте условия исторического протокола и разблокировки EXAM. Не подбирайте параметры по опубликованным ответам EXAM. Для Bash может потребоваться Linux/WSL.

## Метрики
Новые формы отклика H90: F23 90/96 против F22 33/96 и F21-P2 0/96. Новая топология + отклик H90: 69/72 против 32/72 и 0/72. Родное семейство F22: 63/64 против 0/64. Интерпретируйте H90/H16 и точность конечного состояния/всей траектории по исходному протоколу, а не как единый benchmark. NLL: меньше — лучше. Исходные отчёты содержат знаменатели и отрицательные контроли.
